# BodhCode Studio — VS Code Extension

Official VS Code OSS extension for BodhCode Studio.

## Features
- **Deterministic AST Dependency Map**: Visualizes full repository topology powered by Tree-Sitter parsing and graph mathematics.
- **Dual Authentication**: Welcome integration for ChatGPT and GitHub credentials.
- **AI Agent & Grok Model Configuration**: Direct access to xAI Grok (`gpt-oss-120b`, `grok-2`, `grok-beta`).
- **Embedded Local Browser**: Webview browser with live preview, DOM inspector, and viewport screenshot capture for visual debugging.
- **Multilingual Repo Reader**: Instant translation of foreign repository READMEs, issues, and PRs into English or preferred language.
- **ExecPolicy Permission Guard**: Prompts user modal confirmation before destructive actions or file modifications.
